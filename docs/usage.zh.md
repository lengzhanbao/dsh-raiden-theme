# 使用说明

> **首次安装？** 请看 [install.zh.md](install.zh.md)（一条命令、无需构建）。

## 快速开始

1. 安装插件（见 [README](../README.md)）
2. 刷新 DSH Web
3. **设置 → 通用 → 雷电将军工房** 调节外观
4. （可选）在 Agent 预设中选择 **「Raiden 雷电将军」** 启用雷电将军口吻

皮肤与说话方式相互独立：关掉 雷电模式只影响界面；要雷电将军口吻需单独选预设。

## 浅色与深色

主题**没有**单独的日夜开关，跟随 DSH 全局外观：

**设置 → 外观 → 浅色 / 深色 / 跟随系统**

| 项目 | 浅色 | 深色 |
| --- | --- | --- |
| 舞台壁纸 | 花房日光 | 霓虹舞台 |
| 左右立绘 | 日常造型 | 舞台/礼服造型 |
| 面板与纱幕 | 暖色半透明 | 深紫半透明，按钮轻微粉金光晕 |
| Agent 状态色 | 粉 / 薰衣草 / lens 配色 | 同系列深色相位 |

## 透明度与显示

路径：**设置 → 通用 → 雷电将军工房**

设置保存在浏览器 `localStorage`（键名 `dsh-raiden-theme:v1`），卸载插件后恢复默认。所有滑块范围 **0–100%**，修改后立即生效。

| 设置项 | 默认值 | 说明 |
| --- | ---: | --- |
| 雷电将军工房 | 关 | 总开关；开启后显示全部皮肤装饰 |
| 边框透明度 | 42% | 对话区粉紫外框 |
| 面板透明度 | 42% | 侧栏、对话区、输入框底色 |
| 背景纱 | 6% | 壁纸上的半透明幕布，越高文字越易读 |
| 亚克力透明度 | 38% | 仅影响标记为亚克力的表面 |
| 左侧立绘 | 开 | 画面左侧大立绘（融合壁纸模式下通常隐藏） |
| 右侧立绘 | 开 | 画面右侧立绘 |
| 立绘透明度 | 100% | 立绘层整体不透明度 |
| 工作区 Q 版动图 | 开 | 侧栏工作区区域的 Q 版拳击/闪电循环动图 |
| 减弱动效 | 关 | 关闭循环光晕、粒子、动图（改用静帧） |

### 调节建议

- 背景太花、字看不清 → **背景纱** 调到 14%–18%
- 对话框发灰 → 略提高 **面板透明度**
- 想多看壁纸 → 降低 **背景纱**
- 不想看侧栏动图 → 关闭 **工作区 Q 版动图**
- 深色光晕太亮 → 开启 **减弱动效**，并略升 **背景纱**

亚克力为 **按需启用**：只有显式声明亚克力的节点才会磨砂，不会覆盖其他插件。

## Raiden 雷电将军预设

在 **Agent 预设** 中选择 **「Raiden 雷电将军」**。基于标准工具集，编码能力不缩水。

### 角色设定

模型扮演 **雷电将军** 同人形象 —— 在 DSH 里是沉稳、简洁的技术助手：

- 稻妻式庄重口吻，先结论后细节
- 不冒充游戏官方，不编造未公开剧情
- 技术内容必须准确；用户要求简短时直接作答

### 说话方式

- 简洁、有条理，偶尔带一点永恒/稻妻意象
- 用户要求简洁或话题严肃时，去掉修辞，直接给步骤
- 不泄露密钥或隐私

### 写代码时

- 不知道就说不知道，不编造路径、日志、工具输出
- 普通问题：结论 → 原因 → 步骤 → 验证
- 代码问题：定位 → 根因 → 最小改动 → 测试 → 风险

System prompt 源文件：`presets/raiden/`（安装后位于插件包内）。
